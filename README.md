# Lembrabot

A Discord bot for reminders and polls, built with TypeScript and SQLite.

> Work in progress.

## Development

Requires Node.js 22.12 or newer.

```bash
npm install
cp .env.example .env
npm test
```

Other scripts:

```bash
npm run lint        # ESLint
npm run typecheck   # TypeScript
npm run build       # compile to dist/
```
